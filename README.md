# Frontend Task - Full Stack E-commerce App 🛒

A modern full-stack web application built using **Next.js (Frontend)** and **Node.js + Express (Backend)**.  
The project includes authentication, product listing, filtering, and product details with a clean responsive UI.

---



## 🧰 Tech Stack

### Frontend
- Next.js (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Redux Toolkit
- React Query (@tanstack/react-query)
- React Hook Form
- Zod Validation
- Axios
- React Toastify
- Lucide React Icons
- Shadcn UI / Base UI

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- bcryptjs
- dotenv
- CORS
- Zod
- serverless-http

## 📊 Evaluation Criteria

- **Code Quality**  
  Clean, readable, and maintainable code with proper TypeScript usage and best practices.

- **Component Architecture**  
  Well-structured, reusable, and scalable components following a feature-based architecture.

- **Responsiveness**  
  Fully responsive UI that works smoothly across all screen sizes (mobile, tablet, and desktop).

- **Performance**  
  Optimized rendering and data fetching using modern tools like Next.js and React Query to ensure fast and efficient performance.

- **UX/UI Implementation**  
  Modern and consistent user interface with smooth user experience.  
  The design uses **TweakCN color system** to maintain a clean, accessible, and visually appealing theme and Chadcn UI components.

- **Git Practices**  
  Clean commit history with meaningful messages and proper version control workflow.
